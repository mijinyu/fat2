FAT 2급 계산 문제는 결국 아래 7가지 식에서 나옵니다. 식을 외우는 게 아니라 순서를 외우세요.

문제로 풀어보려면 위 유형 → 🧮 계산 칩을 누르세요.

1. 상품매매 흐름

순매입액 = 총매입 + 매입운임 − 매입에누리·환출 − 매입할인 순매출액 = 총매출 − 매출에누리·환입 − 매출할인 매출원가 = 기초상품 + 순매입 − 기말상품 매출총이익 = 순매출액 − 매출원가

역산도 자주 나옴

기말상품 = 기초상품 + 순매입 − 매출원가 순매입 = 매출원가 − 기초상품 + 기말상품

운임 방향을 조심하세요. 살 때 낸 운임은 상품 원가에 더하고, 팔 때 낸 운임은 운반비(비용)로 따로 뺍니다. 매출원가 계산에 안 들어갑니다.

2. 재고 단가결정

선입선출법 → 먼저 산 것부터 팔림. 창고엔 최근에 산 것이 남음 총평균법 → 평균단가 = 총원가 ÷ 총수량 (기간 전체를 한 번에) 이동평균법 → 매입할 때마다 평균단가를 다시 계산

기말재고를 잘못 잡으면 이익이 반대로 움직입니다.
기말재고 과대 → 매출원가 과소 → 당기순이익 과대
기말재고 과소 → 매출원가 과대 → 당기순이익 과소

3. 채권과 대손

기말 매출채권 = 기초 + 외상매출 − 현금회수 − 대손처리 기말 외상매입금 = 기초 + 외상매입 − 지급액

대손충당금 (보충법)

추가설정액 = 채권잔액 × 설정률 − 설정 전 충당금잔액 기말 충당금잔액 = 기초 − 당기 대손처리 + 당기 설정액 대손 확정 시 대손상각비 = 대손액 − 충당금잔액 (모자란 만큼만)

계정과목이 갈립니다. 매출채권 대손은 대손상각비(판관비), 대여금·미수금 같은 기타채권 대손은 기타의대손상각비(영업외비용)입니다.

4. 유형자산

취득원가 = 구입대금 + 취득부대비용 (운반비·설치비·시운전비·취득세·등록면허세·중개수수료) ※ 취득 후 재산세·보험료는 원가에 넣지 않고 그해 비용

감가상각

정액법 = (취득원가 − 잔존가치) ÷ 내용연수 × 사용월수 ÷ 12 정률법 = 장부금액(미상각잔액) × 상각률 ← 해마다 기준이 줄어듦

처분

장부금액 = 취득원가 − 감가상각누계액 처분손익 = 처분금액 − 장부금액 처분금액 > 장부금액 → 유형자산처분이익 (영업외수익) 처분금액 < 장부금액 → 유형자산처분손실 (영업외비용)

취득원가에서 바로 빼면 틀립니다. 감가상각누계액이 주어졌다면 반드시 장부금액부터 구하세요. 이게 가장 흔한 실수입니다.

5. 손익계산서 단계

매출총이익 = 매출액 − 매출원가 영업이익 = 매출총이익 − 판매비와관리비 당기순이익 = 영업이익 + 영업외수익 − 영업외비용

영업이익에 넣지 않는 것

이자비용 · 이자수익 · 기부금 · 잡손실 · 잡이익 유형자산처분손익 · 단기매매증권 처분·평가손익 · 배당금수익 → 전부 영업외. 당기순이익 단계에서만 반영

판관비인지부터 판단하세요. 급여·복리후생비·접대비·임차료·감가상각비·대손상각비·광고선전비·차량유지비·세금과공과금은 판관비라서 영업이익에서 뺍니다.

6. 결산 기간배분 (월할)

선급비용 = 지급액 × 미경과 월수 ÷ 전체 월수 선수수익 = 수령액 × 미경과 월수 ÷ 전체 월수 미수수익 = 원금 × 연이율 × 경과 월수 ÷ 12 미지급비용 = 원금 × 연이율 × 경과 월수 ÷ 12

세는 방향

선급·선수 → 아직 안 지난 개월수 (다음 해 몫) 미수·미지급 → 이미 지나간 개월수 (올해 몫인데 돈은 아직)

예시. 9월 1일에 1년분 보험료 1,200,000원을 냈다면 9~12월 4개월은 올해 몫, 남은 8개월이 선급비용 → 1,200,000 × 8/12 = 800,000원.

7. 등식과 집계

자산 = 부채 + 자본 자본 = 자산 − 부채 기말자본 = 기초자본 + 추가출자 − 인출액 + 당기순이익 시산표 등식: 기말자산 + 총비용 = 기말부채 + 기초자본 + 총수익

현금및현금성자산에 넣는 것 / 빼는 것

넣음: 통화 · 타인발행수표 · 자기앞수표 · 우편환증서 보통예금 · 당좌예금 · 취득 당시 만기 3개월 이내 금융상품 뺌: 받을어음(매출채권) · 우표·수입인지 · 선일자수표 정기예금(만기 3개월 초과) · 당좌차월(→ 단기차입금)

단기매매증권 취득원가에는 수수료를 넣지 않습니다. 수수료비용으로 바로 처리해요. 유형자산과 정반대라 자주 나옵니다.

자주 틀리는 곳만 모아보기

1. 처분손익 → 취득원가 아니라 장부금액과 비교 2. 선급·선수 → 안 지난 개월수 / 미수·미지급 → 지나간 개월수 3. 영업이익 → 이자·기부금·처분손익 제외 4. 매입운임은 원가에 포함, 매출운반비는 비용 5. 대손충당금은 보충법 — 필요액에서 있는 걸 빼고 모자란 만큼만 6. 단기매매증권 수수료는 비용, 유형자산 부대비용은 원가 7. 기말재고 과대 → 이익 과대 (원가가 줄어드니까)
