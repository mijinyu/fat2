1. 처분손익 → 취득원가 아니라 장부금액과 비교 2. 선급·선수 → 안 지난 개월수 / 미수·미지급 → 지나간 개월수 3. 영업이익 → 이자·기부금·처분손익 제외 4. 매입운임은 원가에 포함, 매출운반비는 비용 5. 대손충당금은 보충법 — 필요액에서 있는 걸 빼고 모자란 만큼만 6. 단기매매증권 수수료는 비용, 유형자산 부대비용은 원가 7. 기말재고 과대 → 이익 과대 (원가가 줄어드니까)

FAT 2급 계산 문제는 결국 아래 7가지 식에서 나옵니다. 식을 외우는 게 아니라 순서를 외우세요.

문제로 풀어보려면 기존문제·심화문제 탭에서 유형 → 🧮 계산 칩을 누르세요. (기출 50 · 심화 36)

1. 상품매매 흐름

순매입액 = 총매입 + 매입운임 − 매입에누리·환출 − 매입할인 순매출액 = 총매출 − 매출에누리·환입 − 매출할인 매출원가 = 기초상품 + 순매입 − 기말상품 매출총이익 = 순매출액 − 매출원가

역산도 자주 나옴

기말상품 = 기초상품 + 순매입 − 매출원가 순매입 = 매출원가 − 기초상품 + 기말상품

운임 방향을 조심하세요. 살 때 낸 운임은 상품 원가에 더하고, 팔 때 낸 운임은 운반비(비용)로 따로 뺍니다. 매출원가 계산에 안 들어갑니다.

2. 재고 단가결정

선입선출법 → 먼저 산 것부터 팔림. 창고엔 최근에 산 것이 남음 총평균법 → 평균단가 = 총원가 ÷ 총수량 (기간 전체를 한 번에) 이동평균법 → 매입할 때마다 평균단가를 다시 계산

기말재고를 잘못 잡으면 이익이 반대로 움직입니다.
기말재고 과대 → 매출원가 과소 → 당기순이익 과대
기말재고 과소 → 매출원가 과대 → 당기순이익 과소

3. 채권과 대손

기말 매출채권 = 기초 + 외상매출 − 현금회수 − 대손처리 기말 외상매입금 = 기초 + 외상매입 − 지급액

대손충당금 (보충법)

추가설정액 = 채권잔액 × 설정률 − 설정 전 충당금잔액 기말 충당금잔액 = 기초 − 당기 대손처리 + 당기 설정액 대손 확정 시 대손상각비 = 대손액 − 충당금잔액 (모자란 만큼만)

계정과목이 갈립니다. 매출채권 대손은 대손상각비(판관비), 대여금·미수금 같은 기타채권 대손은 기타의대손상각비(영업외비용)입니다.

4. 유형자산

취득원가 = 구입대금 + 취득부대비용 (운반비·설치비·시운전비·취득세·등록면허세·중개수수료) ※ 취득 후 재산세·보험료는 원가에 넣지 않고 그해 비용

감가상각

정액법 = (취득원가 − 잔존가치) ÷ 내용연수 × 사용월수 ÷ 12 정률법 = 장부금액(미상각잔액) × 상각률 ← 해마다 기준이 줄어듦

처분

장부금액 = 취득원가 − 감가상각누계액 처분손익 = 처분금액 − 장부금액 처분금액 > 장부금액 → 유형자산처분이익 (영업외수익) 처분금액 < 장부금액 → 유형자산처분손실 (영업외비용)

취득원가에서 바로 빼면 틀립니다. 감가상각누계액이 주어졌다면 반드시 장부금액부터 구하세요. 이게 가장 흔한 실수입니다.

5. 손익계산서 단계

매출총이익 = 매출액 − 매출원가 영업이익 = 매출총이익 − 판매비와관리비 당기순이익 = 영업이익 + 영업외수익 − 영업외비용

영업이익에 넣지 않는 것

이자비용 · 이자수익 · 기부금 · 잡손실 · 잡이익 유형자산처분손익 · 단기매매증권 처분·평가손익 · 배당금수익 → 전부 영업외. 당기순이익 단계에서만 반영

판관비인지부터 판단하세요. 급여·복리후생비·접대비·임차료·감가상각비·대손상각비·광고선전비·차량유지비·세금과공과금은 판관비라서 영업이익에서 뺍니다.

6. 결산 기간배분 (월할)

선급비용 = 지급액 × 미경과 월수 ÷ 전체 월수 선수수익 = 수령액 × 미경과 월수 ÷ 전체 월수 미수수익 = 원금 × 연이율 × 경과 월수 ÷ 12 미지급비용 = 원금 × 연이율 × 경과 월수 ÷ 12

세는 방향

선급·선수 → 아직 안 지난 개월수 (다음 해 몫) 미수·미지급 → 이미 지나간 개월수 (올해 몫인데 돈은 아직)

예시. 9월 1일에 1년분 보험료 1,200,000원을 냈다면 9~12월 4개월은 올해 몫, 남은 8개월이 선급비용 → 1,200,000 × 8/12 = 800,000원.

7. 등식과 집계

자산 = 부채 + 자본 자본 = 자산 − 부채 기말자본 = 기초자본 + 추가출자 − 인출액 + 당기순이익 시산표 등식: 기말자산 + 총비용 = 기말부채 + 기초자본 + 총수익

현금및현금성자산에 넣는 것 / 빼는 것

넣음: 통화 · 타인발행수표 · 자기앞수표 · 우편환증서 보통예금 · 당좌예금 · 취득 당시 만기 3개월 이내 금융상품 뺌: 받을어음(매출채권) · 우표·수입인지 · 선일자수표 정기예금(만기 3개월 초과) · 당좌차월(→ 단기차입금)

단기매매증권 취득원가에는 수수료를 넣지 않습니다. 수수료비용으로 바로 처리해요. 유형자산과 정반대라 자주 나옵니다.

🔑 이거 하나면 분개의 절반

자비는 왼쪽 자산↑ · 비용↑ → 차변 부자수는 오른쪽 부채↑ · 자본↑ · 수익↑ → 대변

줄어들면 반대쪽으로 갑니다. 자산이 줄면 대변, 부채가 줄면 차변. "자비는 왼쪽, 부자수는 오른쪽"만 입에 붙여두면 웬만한 분개는 손이 먼저 움직입니다.

🔑 영업외만 외우세요

이 · 기 · 처 · 평 · 잡 이자 · 기부금 · 처분손익 · 평가손익 · 잡손익 (+ 배당금수익 · 임대료)

판관비는 스무 개가 넘는데 영업외는 이게 전부입니다. 여기 없으면 판관비로 처리하세요. 영업이익 계산 문제가 거의 다 풀립니다.

결산 방향 — 미(未)냐 선(先)이냐

미 = 아직 안 받았/안 줬다 → 올해 몫 → 지나간 개월수 선 = 먼저 받았/먼저 줬다 → 내년 몫 → 안 지난 개월수
미 (발생)미수수익 — 받을 이자
미지급비용 — 낼 이자·급여
선 (이연)선급비용 — 미리 낸 보험료
선수수익 — 미리 받은 임대료

개월수를 반대로 세는 것이 결산 계산에서 제일 흔한 실수입니다. 9월에 1년치 보험료를 냈다면 선급비용은 남은 8개월치예요.

계정 이름만 보고 가르기

"금"이 붙으면 → 상품 거래의 계약금 (선급금 · 선수금) "비용·수익"이 붙으면 → 결산 기간배분 (선급비용 · 선수수익) 상품 거래면 → 외상매출금 · 외상매입금 상품이 아니면 → 미수금 · 미지급금 ("상품 아니면 미")

짧은 것 세 개

국민만 세금 건강·고용·산재 회사부담 → 복리후생비 국민연금 회사부담 → 세금과공과금 땅은 안 닳고, 짓는 중은 아직 안 쓴다 토지 · 건설중인자산 → 감가상각 안 함 대 · 감 · 인 (차감계정 3형제) 대손충당금(자산↓) · 감가상각누계액(자산↓) · 인출금(자본↓)

부대비용을 얹느냐

오래 쓸 것 → 얹음유형자산
운반·설치·시운전·취득세
→ 취득원가에 포함
곧 팔 것 → 안 얹음단기매매증권
매입수수료
→ 수수료비용으로 바로 비용

정반대라서 시험에 잘 나옵니다. "곧 팔 건 원가를 안 불린다"로 기억하세요.

흐름 두 가지

매출원가 있던 거 + 사온 거 − 남은 거 = 팔린 거 기초 + 순매입 − 기말 = 매출원가 장부 순서 분 · 총 · 시 · 재 분개장 → 총계정원장 → 시산표 → 재무제표

⚠️ 시험 직전 30초 훑기

자비는 왼쪽 / 부자수는 오른쪽 영업외는 이·기·처·평·잡 — 나머지는 판관비 미는 지나간 개월 / 선은 안 지난 개월 처분손익은 장부금액과 비교 (취득원가 아님) 매입운임은 더하고, 에누리·환출·할인은 뺀다 대손충당금은 보충법 — 모자란 만큼만 국민연금만 세금과공과금, 나머지는 복리후생비 기말재고 과대 → 이익 과대

재무상태표는 자산 = 부채 + 자본. 계정과목이 어느 칸에 앉는지만 알면 절반은 맞힙니다.

자산 — 유동자산

당좌자산 (바로 현금화)

현금및현금성자산 · 단기금융상품 · 단기매매증권 외상매출금 · 받을어음 ← 둘을 합쳐 매출채권 미수금 · 미수수익 · 선급금 · 선급비용 단기대여금 · 가지급금 · 현금과부족(임시)

재고자산 (팔려고 보유)

상품 ← FAT 2급(도소매)은 사실상 상품 하나

차감계정 주의. 대손충당금은 매출채권 아래에 빼는 형식으로 붙습니다. 자산이지만 부호가 반대예요.

자산 — 비유동자산

투자자산 장기금융상품 · 장기대여금 · 투자부동산 유형자산 토지 · 건물 · 구축물 · 기계장치 차량운반구 · 비품 · 건설중인자산 무형자산 영업권 · 산업재산권(특허권·상표권·실용신안권·디자인권) 개발비 · 소프트웨어 기타비유동 임차보증금 · 장기외상매출금

토지와 건설중인자산은 감가상각하지 않습니다. 닳지 않거나 아직 안 쓰고 있어서예요. 감가상각누계액은 유형자산에서 빼는 차감계정입니다.

보증금 방향. 내가 맡긴 임차보증금은 자산, 내가 받은 임대보증금은 부채입니다.

부채

유동부채 (1년 안에 갚음) 외상매입금 · 지급어음 ← 둘을 합쳐 매입채무 미지급금 · 미지급비용 · 선수금 · 선수수익 예수금 · 가수금 · 단기차입금 · 유동성장기부채 비유동부채 (1년 넘게 뒤) 장기차입금 · 임대보증금

유동성장기부채는 원래 장기차입금이었다가 만기가 1년 안으로 들어온 것입니다. 처음부터 짧게 빌린 단기차입금과 구분하세요.

자본 — 개인기업

자본금 ← 개인기업은 자본 계정이 사실상 이것 하나 인출금 ← 결산 때 자본금에서 빼고 없앰 (차감) 기말자본 = 기초자본 + 추가출자 − 인출액 + 당기순이익

법인의 이익잉여금·자본잉여금·주식발행은 FAT 2급 범위가 아닙니다. 개인기업 기준으로만 보세요.

차감계정 3형제

대손충당금 → 매출채권에서 뺌 (자산 차감) 감가상각누계액 → 유형자산에서 뺌 (자산 차감) 인출금 → 자본금에서 뺌 (자본 차감)

셋 다 "있는데 빼는" 계정입니다. 시산표에는 대변에 나타나지만 자산·자본 쪽 계정이라 헷갈리기 쉬워요.

손익계산서는 매출총이익 → 영업이익 → 당기순이익 3단계. 계정이 판관비냐 영업외냐만 가르면 됩니다.

판매비와관리비 (영업이익에서 뺌)

인건비 급여 · 잡급 · 상여금 · 퇴직급여 · 복리후생비 활동비 여비교통비 · 접대비(기업업무추진비) · 운반비 차량유지비 · 교육훈련비 · 광고선전비 사무비 통신비 · 수도광열비 · 소모품비 · 사무용품비 · 도서인쇄비 관리비 임차료 · 보험료 · 수선비 · 수수료비용 · 세금과공과금 상각·대손 감가상각비 · 무형자산상각비 · 대손상각비

결산 절차

1. 수정전시산표 작성 ← 지금까지 적은 것 집계 2. 결산정리분개 ← 기간을 맞추는 작업 (아래 8가지) 3. 수정후시산표 작성 4. 장부 마감 ← 수익·비용은 집합손익으로, 자산·부채·자본은 차기이월 5. 재무제표 작성

장부 작성 순서는 분개장 → 총계정원장 → 시산표 → 재무제표. "분·총·시·재"로 외우세요.
