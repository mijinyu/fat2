# FAT 2급 문제풀이 (92회 대비)

한국공인회계사회 **FAT 2급** 기출(제80~91회)과 심화문제를 폰·PC에서 풀 수 있는 정적 웹앱입니다.
분개(전표입력) 연습에 초점을 맞췄습니다.

## 기능
- **탭 2개**: `기존문제`(회차별) / `심화문제`(이론·분개)
- **필터**: 이론 / 분개 / ❤️92회 예상 / ⭐빈출 / 회차 선택
- **즉시 채점**: 문제마다 `정답 확인` → 맞으면 ⭕, 틀리면 ❌ + 🧒 초등학생 눈높이 해설
- **분개 입력표**: `구분(차/대) · 계정과목 · 거래처 · 금액` 칸, `＋행 추가` 로 행 추가, 계정과목은 코드·괄호·띄어쓰기 무시하고 유연 채점
- **표시**: ⭐(별 개수=빈출도) · ❤️(92회 출제 예상)
- **모바일/PC 반응형**, 풀이 기록 자동 저장(localStorage)

총 **276문항** (기존 이론 120 · 기존 분개 88 · 심화 이론 30 · 심화 분개 38)

## 로컬에서 보기
```bash
node server.js
```
그 후 브라우저에서 http://localhost:4173 접속. (Node.js만 있으면 됩니다)

## GitHub Pages 배포
1. 깃허브에 새 저장소 생성 (예: `fat2-quiz`)
2. 이 폴더를 push
3. 저장소 **Settings → Pages → Source: `main` 브랜치 / `/ (root)`** 선택
4. 몇 분 뒤 `https://<아이디>.github.io/fat2-quiz/` 로 접속 (폰 홈화면에 추가해서 앱처럼 사용)

## 파일 구조
```
index.html        화면 골격
css/style.css     디자인(반응형)
js/app.js         채점·렌더 엔진
js/data.js        문제 데이터(276문항)
server.js         로컬 미리보기용(배포엔 불필요)
```
